# ICT Grade 10 — portfolio-page assignment

**Context:** School project.

A school portfolio-page exercise using animation libraries, section navigation, and a third-party contact-form action.

## Implementation

**Technologies:** HTML, CSS, JavaScript, Typed.js, ScrollReveal, Formspree.

- Typed text and scroll-reveal effects.
- Navigation styling that reacts to scroll position.
- About, services, and contact sections.

## Run locally

Requires Git, Python 3 for the local server, and a modern browser. No build step is included.

```sh
git clone https://github.com/TigerOneTank/ICTU1G10PT.git
cd ICTU1G10PT
python -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000/home.html`. On Windows, `py` can replace `python`. External APIs, fonts, scripts, or embeds require internet access.

Practices integrating browser libraries and organizing a multi-section page. Clarifying authorship, template sources, and sample content is the next step.
